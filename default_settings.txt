# Lists use ; as separator. Booleans: true or false. Empty value = empty text or empty list.
#
# HOW TO SEARCH (Ctrl+F):
#   [S03]       jumps to a section
#   [S03.05]    jumps to one setting
#   key name    example: HomeShowClock
#   any word    example: marquee, wallpaper, video
#
