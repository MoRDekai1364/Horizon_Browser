# Privacy Policy — Horizon Browser

**Last updated:** July 10, 2026

Horizon Browser is a personal, independently developed WPF/WebView2 desktop browser for Windows. This document describes what data the application does — and does not — collect or transmit.

## Data Collection & Transmission

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Horizon Browser does not collect, store, transmit, sell, or share any personal data, browsing history, telemetry, analytics, or usage statistics with the developer or any third party. All browsing data (history, cookies, bookmarks, cache, settings) is stored locally on the user's own machine and is never transmitted off-device by the application itself.

## Third-Party Components

Horizon Browser is built on **Microsoft Edge WebView2**, a Chromium-based rendering engine provided by Microsoft. WebView2 is used to render web content and may independently communicate with sites the user visits, consistent with normal browser behavior (e.g., loading pages, fetching resources the user navigates to). This is standard behavior for any browser rendering the pages a user requests and is not data collection performed by Horizon Browser itself.

For details on Microsoft Edge WebView2's own data handling, see Microsoft's Privacy Statement:
https://privacy.microsoft.com/en-us/privacystatement

Horizon Browser does not add any additional tracking, analytics, or telemetry layers on top of WebView2's default behavior.

## Optional Features

Any feature that would involve network communication beyond normal web browsing (e.g., checking for software updates via GitHub) is either:
- initiated explicitly by user action, or
- disclosed clearly at the point of use.

No such feature transmits personal or identifying data beyond what is technically required to complete the requested action (e.g., a version check against public GitHub release metadata).

## Updates to This Policy

If future versions of Horizon Browser introduce features that collect or transmit user data, this policy will be updated accordingly, and any such feature will include a clear disclosure and an option to disable it.
